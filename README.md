# Trójmiasto — gra historyczna

Publiczny prototyp jednoosobowej gry historycznej opartej na danych GPS projektu Miasto na Mapie. Mechanika 3B: wybór kierunku, dwa możliwe punkty, wybór A/B i ujawnienie danych historycznych dopiero po odwiedzeniu punktu.

Dane gry znajdują się lokalnie w `data/mapa-db.kml`, więc strona nie zależy od prywatnego repozytorium `miastonamapie`.
